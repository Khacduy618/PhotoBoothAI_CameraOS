# MCP Integration Rules

## Required MCP Usage
1. **chrome-devtools MCP**: Use for automated visual preview testing, DOM inspection, FPS profiling, and console log extraction during camera UI work.
2. **filesystem / local-storage MCP**: Use to audit local photo capture storage paths and ensure saved media is persistent and accessible.
3. **cups-printer / hardware MCP**: Use to inspect printer queue status and simulate paper-out / hardware failure states.
