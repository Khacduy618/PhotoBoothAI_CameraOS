# Requirement Analysis

Identify:

- user/operator
- trigger
- expected outcome
- failure behavior
- hardware dependency
- offline behavior
- privacy impact
- acceptance evidence

Output:

- problem statement
- scope
- out of scope
- assumptions
- open questions
- acceptance criteria
